# Chua's Circuit: Basins of Attraction 

## Files
* `consts.h` – Circuit parameters.
* `chua.cpp` – C++ source code. 
* `plot.py` – Python script for visualizing.
* `plots/` – Generated images.

## How to run
1. Compile the C++ code:
   ```bash
   g++ -O3 chua.cpp -o chua
2. Install requirements
   ```bash
   pip install -r requirements.txt
3. Generate the plot
   ```bash
   python3 plot.py
